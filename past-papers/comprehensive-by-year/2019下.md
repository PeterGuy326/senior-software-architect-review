## 第 1-3 题：[§1 计算机系统]

### 1. 【题干】
前趋图（Precedence Graph）是有向无环图，记 →={(Pi,Pj) | Pi 必须在 Pj 前完成}。给定 P={P1..P8}，图中箭头：P1→P2,P1→P3,P1→P4;P2→P5;P3→P5,P3→P6;P4→P7;P5→P6;P6→P7,P6→P8;P7→P8。写出前趋关系集合。
A/B/C 干扰项含 P5→P3、P1→P4 反向等错误对  D. →={(P1,P2),(P1,P3),(P1,P4),(P2,P5),(P3,P5),(P3,P6),(P4,P7),(P5,P6),(P6,P7),(P6,P8),(P7,P8)}
**答案：D**  |  **考点**：§1.2 前趋图/DAG 表示
**解析**：按图逐条边列出偏序对，D 项与图完全一致。

### 2. 【题干】
进程 P 有 8 个页面（0~7），页面大小 4K，分配 4 个存储块。给出页表（状态位=1 在内存：1、2、5、7 号页在内存，页帧号分别为 7、5、3、9）。逻辑地址 5148H 变换后物理地址为（2）。
A. 3148H  B. 5148H  C. 7148H  D. 9148H
**答案：A**  |  **考点**：§1.2 页式存储地址变换
**解析**：5148H 页号=5，帧号=3，页内 148H；物理地址=3148H。

### 3. 【题干】
承上题，若访问页面 6 不在内存，应淘汰页号为（3）的页面（依据 LRU 与是否修改）。
A. 1  B. 2  C. 5  D. 9
**答案：B**  |  **考点**：§1.2 页面置换（LRU）
**解析**：1、5、7 均最近访问过，2 号最近未访问，故淘汰 2。

## 第 71-75 题：[§13 专业英语 — 数据组织与数据库设计]

### 材料
> During the systems analysis phase, you must decide how data will be organized, stored, and managed. A（71）is a framework for organizing and storing data. Each file or table contains data about people, places, things, or events. One of the potential problems existing in a file processing environment is（72）, which means that data common to two or more information systems is stored in several places.
>
> In a DBMS, the linked tables form a unified data structure that greatly improves data quality and access. A(n)（73）is a model that shows the logical relationships and interaction among system entities. It provides an overall view of the system and a blueprint for creating the physical data structures.（74）is the process of creating table designs by assigning specific fields or attributes to each table in the database. A table design specifies the fields and identifies the primary key. The three normal forms constitute a progression in which（75）represents the best design.

### 71. 【题干】
A. data entity  B. data structure  C. file collection  D. data definition
**答案：B**  |  **考点**：§13 专业英语（数据组织框架=data structure）

### 72. 【题干】
A. data integrity  B. the rigid data structure  C. data redundancy  D. the many-to-many relationship
**答案：C**  |  **考点**：§13 专业英语（数据冗余）

### 73. 【题干】
A. entity-relationship diagram  B. data dictionary  C. database schema  D. physical database model
**答案：A**  |  **考点**：§13 专业英语（E-R 图）

### 74. 【题干】
A. Normalization  B. Replication  C. Partitioning  D. Optimization
**答案：A**  |  **考点**：§13 专业英语（规范化）

### 75. 【题干】
A. standard notation form  B. first normal form  C. second normal form  D. third normal form

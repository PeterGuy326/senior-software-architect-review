## 10.1 信息物理系统 CPS 技术

### 定义

**Cyber-Physical Systems**：通过**计算（Computation）、通信（Communication）、控制（Control）**——**3C 技术**——把物理实体与信息系统深度融合，实现对物理世界的**实时感知、动态控制、信息服务**。是"工业 4.0""中国制造 2025"的核心技术底座。

### 三大特征（3C）

| 维度 | 内涵 | 承载技术 |
|---|---|---|
| **Computation 计算** | 分布式实时计算、嵌入式计算、边缘/云协同 | 嵌入式 CPU、边缘节点、云中心 |
| **Communication 通信** | 物理层-信息层双向交互，低时延高可靠 | 工业以太网、TSN、5G、OPC UA |
| **Control 控制** | 闭环反馈、自主决策、协同控制 | PLC、DCS、模型预测控制 MPC |

### 体系架构（4 层）

1. **感知层**：传感器、RFID、执行器 —— 物理数据数字化
2. **网络层**：现场总线 / 工业以太网 / 5G / 卫星 —— 信息传输
3. **认知层**：数据建模、大数据分析、AI 推理 —— 决策生成
4. **控制层**：执行器、机器人、机床 —— 决策落地反作用于物理世界

> 也有教材写作 **"单元级 / 系统级 / SoS 级"** 三层：单元级 = 单个设备闭环；系统级 = 车间/产线联网协同；SoS（System of Systems）级 = 跨企业跨域集成。

### 典型应用

- **智能制造**：数字化车间、柔性产线、预测性维护
- **智慧城市**：智能交通、智能电网（Smart Grid）、智慧水务
- **车联网 V2X**：车-车 / 车-路 / 车-云协同，L4/L5 自动驾驶
- **智慧医疗**：远程手术、可穿戴设备闭环治疗

### 考点角度

- 综合知识：3C 特征名词题、4 层体系架构名词填空
- 案例题：作为**智能制造 / 车联网**背景，考架构分层、可靠性、实时性设计
- 论文：常混入"嵌入式实时 + 分布式"论题（DARTS、ATAM）

## 10.2 人工智能 AI 技术

### 机器学习分类

| 分类 | 数据形式 | 代表算法 | 典型场景 |
|---|---|---|---|
| **监督学习** | 有标签 (X, y) | 线性回归、SVM、决策树、随机森林、XGBoost、CNN | 分类、回归、图像识别 |
| **无监督学习** | 只有 X | K-Means、DBSCAN、PCA、Apriori、Auto-Encoder | 聚类、降维、关联分析 |
| **半监督学习** | 少量标签 + 大量无标签 | Self-Training、Co-Training | 标注成本高的场景 |
| **强化学习 RL** | 状态-动作-奖励 (s,a,r) | Q-Learning、DQN、A3C、PPO | 机器人、游戏 AI、调度 |

### 深度学习基本模型

| 模型 | 结构要点 | 擅长 |
|---|---|---|
| **CNN 卷积神经网络** | 卷积核 + 池化 + 全连接；局部感受野、权值共享 | 图像、视觉 |
| **RNN / LSTM / GRU** | 时序循环、门控记忆 | 语音、文本、时序预测 |
| **Transformer** | Self-Attention 自注意力，无循环、可并行 | NLP、大模型 (BERT/GPT)、多模态 |
| **GAN 生成对抗** | 生成器 + 判别器博弈 | 图像生成、风格迁移 |
| **图神经网络 GNN** | 消息传递聚合邻居 | 社交、推荐、知识图谱 |

### 专家系统与 AI 的关系（对照 §2.5）

- **专家系统 ES** 是 AI 的**早期符号主义**分支：知识库 + 推理机 + 解释器 + 知识获取 + 人机界面（教材 5 组件）
- 现代 AI 走**连接主义 + 数据驱动**路线，二者可融合：**神经-符号混合系统**（Neuro-Symbolic）
- 考试中 ES 常与"知识库、推理机、规则库"考点绑定，属 §2 信息系统基础

### AI 在软件架构中的应用

- **智能决策**：营销自动化、动态定价、供应链调度
- **推荐系统**：协同过滤 → 深度召回 + 精排
- **预测**：容量预测、故障预测（AIOps）
- **异常检测**：安全入侵、金融风控、日志异常
- **智能运维 AIOps**：日志聚类、根因分析、自愈

### 考点角度

- 综合知识：ML 三大分类名词题、CNN/RNN/Transformer 用途辨析
- 案例题：AI 中台、推荐架构、AIOps 作为**可选大题背景**
- 论文：可入"系统设计"方向的智能子系统章节

## 10.3 机器人技术

### 分类

| 类型 | 场景 | 代表 |
|---|---|---|
| **工业机器人** | 结构化环境、重复作业 | 焊接、搬运、装配（ABB、发那科、库卡、安川"四大家族"） |
| **服务机器人** | 半结构化环境，服务于人 | 家政、教育、医疗、餐饮（扫地机、送餐机） |
| **特种机器人** | 非结构化极端环境 | 军事、消防、深海、太空、核工业 |

按代际还常分为：**示教再现型（第 1 代） → 感知型（第 2 代） → 智能型（第 3 代，自主决策）**。

### 体系架构（3 层）

1. **感知层**：视觉、激光雷达、力觉、IMU —— 环境建模、SLAM 定位
2. **决策层**：路径规划、任务规划、行为决策 —— AI/规则引擎
3. **执行层**：伺服电机、舵机、抓手 —— 动作输出

### 与 AI / CPS 的关系

- 机器人 = **CPS 在移动/操作场景的具体实例化**：感知-决策-执行闭环 = CPS 3C 的落地
- AI 提供机器人"大脑"（视觉识别、路径规划、强化学习控制策略）
- 因此 **CPS ⊇ 机器人**，机器人 = 特殊形态的 CPS 智能体

### 考点角度

- 综合知识：三代分类、体系架构 3 层选择题
- 案例题：作为**智能工厂**背景出现，配合 CPS/工业互联网考察

## 10.4 边缘计算技术

### 定义

**Edge Computing**：把计算、存储、网络能力**下沉到数据源头**（近端），在数据产生的物理位置附近就地处理，**降低时延、减少回传带宽、增强隐私、提高可靠性**。

### 与云计算对比

| 维度 | 云计算 | 边缘计算 |
|---|---|---|
| 位置 | 集中式数据中心 | 靠近数据源（基站/网关/终端） |
| 时延 | 数十~数百 ms | ms 级 |
| 带宽 | 依赖回传，成本高 | 就近处理，回传少 |
| 算力 | 弹性极强，几乎无上限 | 单节点算力有限，需协同 |
| 数据 | 全量集中 | 本地保留敏感数据 |
| 场景 | 长周期批处理、AI 训练 | 实时控制、AI 推理 |

云边协同（Cloud-Edge Collaboration）是主流：**云训练、边推理；云管理、边执行**。

### 典型场景

- **5G MEC 移动边缘计算**：见 §7.1 通信系统架构 —— 5GS 与 DN 互连、UPF 下沉
- **车联网 V2X**：路侧单元 RSU 提供毫秒级决策
- **工业互联网**：现场级 PLC + 边缘网关，OT/IT 融合
- **IoT / 智慧安防**：视频结构化在边缘完成，只回传结构化元数据
- **CDN 内容分发**：静态内容边缘缓存（历史悠久的边缘形态）

### 考点角度

- 综合知识：**云边对比表**必考选择题
- 案例题：**5G 网络应用**（§7.5）、**智能制造**背景高频引用
- 论文：可作为"系统性能设计""高可用架构"支撑技术

## 10.5 数字孪生技术

### 定义

**Digital Twin**：物理实体（设备、产线、城市、人体）在信息空间的**高保真数字镜像**，通过实时数据双向同步，实现对物理实体的**监测、仿真、预测、优化**。

**四要素**：物理实体 + 虚拟模型 + 数据 + 服务；**核心特征**：**实时性、双向映射、闭环优化**。

### 5 大能力（分层递进）

| 层级 | 能力 | 内涵 |
|---|---|---|
| L1 | **描述 Describe** | 数字化再现物理实体当前状态（可视化） |
| L2 | **诊断 Diagnose** | 追溯问题根因（"发生了什么、为什么"） |
| L3 | **预测 Predict** | 基于模型 + 历史数据预测未来（RUL 剩余寿命） |
| L4 | **决策 Decide** | 给出优化决策方案 |
| L5 | **优化 Optimize** | 决策反哺物理实体，形成闭环自主优化 |

### 数字孪生 vs CPS（易混辨析）

| 维度 | CPS | 数字孪生 |
|---|---|---|
| 侧重 | 物理系统的**控制**（Control 是核心 C） | 物理系统的**镜像与仿真** |
| 关系 | 系统整体范式 | CPS 的**信息侧建模手段**之一 |
| 输出 | 直接驱动执行器 | 输出决策建议 / 仿真结果 |
| 关键词 | 感知-通信-控制闭环 | 建模、仿真、镜像、可视化 |

一句话：**"数字孪生是 CPS 认知层的核心表达"**，二者不是替代关系，而是包含+互补关系。

### 典型应用

- **智慧工厂**：产线孪生，仿真排产、预测性维护
- **智慧城市**：城市信息模型 CIM，交通/能源/水务孪生
- **智慧医疗**：器官孪生、手术仿真
- **航空航天**：发动机孪生（GE、罗罗），全生命周期健康管理

### 考点角度

- 综合知识：**5 大能力顺序**、与 CPS 区别，是新增高频名词题
- 案例题：智能制造/智慧城市案例背景板
- 论文："架构演化""系统建模"方向可写数字孪生建模

## 10.6 云计算和大数据技术

### 云计算服务模型

| 模型 | 交付层次 | 举例 | 用户负责 |
|---|---|---|---|
| **IaaS** 基础设施 | 计算/存储/网络（虚机） | AWS EC2、阿里云 ECS | OS 及以上 |
| **PaaS** 平台 | 运行时/中间件/DB | 阿里云 EDAS、Heroku | 应用及数据 |
| **SaaS** 软件 | 完整应用 | 钉钉、Salesforce、Office 365 | 仅数据/配置 |
| （补充）**FaaS / BaaS** | 无服务器 | AWS Lambda、函数计算 | 只写函数 |

### 云部署模型

- **公有云**：AWS、阿里云、华为云 —— 多租户共享
- **私有云**：企业自建（OpenStack、VMware）—— 独享
- **混合云**：公+私联动，敏感数据私有、弹性公有
- **社区云**：多个组织共享（如政务云、金融云、行业云）

### 容器 vs 虚拟化

| 维度 | 虚拟机 VM | 容器 Container |
|---|---|---|
| 隔离层次 | Hypervisor（Type 1/2） | 内核 Namespace + Cgroup |
| 启动 | 分钟级 | 秒级 |
| 镜像 | GB 级 | MB 级 |
| OS | 独立 GuestOS | 共享宿主内核 |
| 密度 | 单机数十 | 单机数百~千 |
| 代表 | VMware、KVM、Xen | Docker、containerd |
| 编排 | vCenter | Kubernetes |

### 大数据 4V 特征

- **Volume** 体量大（PB/EB 级）
- **Velocity** 高速度（流式、实时）
- **Variety** 多样性（结构化 / 半结构化 / 非结构化）
- **Value** 价值密度低但价值总量高

> 也有教材加第 5 V — **Veracity** 真实性。

### 大数据架构（详见 [`../18-case-big-data/`](../18-case-big-data/)、§9 案例章）

| 架构 | 组成 | 特点 |
|---|---|---|
| **Lambda** | **Batch Layer + Speed Layer + Serving Layer** | 离线+实时双链路，准确但复杂 |
| **Kappa** | 仅流处理，历史数据"回放"重算 | 单链路，简单但重放成本高 |
| **Kappa 变形** | 加旁路批量校正 | 折中方案 |

### Hadoop 生态组件定位

| 组件 | 定位 |
|---|---|
| **HDFS** | 分布式文件系统（存） |
| **YARN** | 资源调度 |
| **MapReduce** | 离线批处理（老） |
| **Spark** | 内存迭代计算，批+流一体（RDD/DataFrame） |
| **Flink** | 真流式（Event Time、Exactly-Once），实时首选 |
| **Kafka** | 分布式消息队列，日志/流数据管道 |
| **Hive** | HDFS 上的 SQL 引擎（离线数仓） |
| **HBase** | 列式 NoSQL（宽表随机读写） |
| **ZooKeeper** | 分布式协调 |

### 考点角度

- 综合知识：**IaaS/PaaS/SaaS 归属**、**4V**、**容器 vs 虚机**几乎每年必考
- 案例题：大数据 4 道选做题之一（Lambda/Kappa 架构画图 + 组件选型）
- 论文：**大数据处理系统流程设计**是论文 5 大方向之一

## 必背要点速记

1. 官方 §10 = **6 项**：CPS / AI / 机器人 / 边缘计算 / 数字孪生 / 云计算+大数据。**区块链、AIGC 不在大纲内**。
2. **CPS 3C** = Computation / Communication / Control；4 层 = 感知/网络/认知/控制。
3. **ML 三分类** = 监督 / 无监督 / 强化；深度学习三大件 = CNN(图像) / RNN(时序) / Transformer(NLP+大模型)。
4. **专家系统 5 组件** = 知识库 + 推理机 + 解释器 + 知识获取 + 人机界面（§2.5 老考点）。
5. **机器人 3 代** = 示教再现 → 感知 → 智能；架构 3 层 = 感知 / 决策 / 执行；机器人 ⊂ CPS。
6. **云边对比 5 要素** = 位置 / 时延 / 带宽 / 算力 / 场景；**云训练边推理**是主流协同模式。
7. **数字孪生 5 能力**（顺序！）= 描述 → 诊断 → 预测 → 决策 → 优化；**数字孪生 ≠ CPS，是 CPS 的信息侧建模**。
8. **云服务模型** IaaS/PaaS/SaaS + FaaS/BaaS；**部署模型** 公/私/混/社区。
9. **容器 vs VM** 一图记忆：内核共享 vs Hypervisor 隔离；秒启 vs 分钟启；MB vs GB。
10. **大数据 4V** = Volume/Velocity/Variety/Value；架构 = **Lambda（Batch+Speed+Serving）/ Kappa（纯流）**；组件 = HDFS+YARN+Spark+Flink+Kafka。

# 02 · 信息系统基础知识（教材第 3 章 / 大纲 §2）

> 综合选择 1–3 题，占 1.3–4%。以 TPS/MIS/DSS/ES/OAS/ERP 六大系统对比 + 开发方法辨析为主。

## §2.1 信息系统概述

### 定义与要素

信息系统 = 由计算机硬件 + 网络 + 通信设备 + 软件 + 数据资源 + 人员构成的、以处理**信息流**为目的的**人机一体化系统**。

### 五大功能

**输入 → 存储 → 处理 → 输出 → 控制**（信息的采集、加工、传输、存储、维护、使用）。

### 发展六阶段（诺兰模型）

初装 → 蔓延 → 控制 → 集成 → 数据管理 → 成熟。

### 生命周期四阶段（必背）

| 阶段 | 主要工作 | 交付物 |
|---|---|---|
| **立项（系统规划）** | 需求调研、可行性研究 | 立项报告、可行性研究报告 |
| **开发** | 需求分析、系统设计、实施 | 需求规格、设计说明、代码、测试报告 |
| **运维** | 上线、日常运维、优化 | 运维报告、变更单 |
| **消亡** | 废弃、替换、数据迁移 | 迁移方案 |

### 建设五原则（必背）

**高层管理人员介入、用户参与、自顶向下规划、工程化方法、创新性**。

### 开发方法对比（必背）

| 方法 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| **结构化方法 SASD** | 需求清晰稳定的 MIS | 严格、文档规范、易掌握 | 不适应需求变化，周期长 |
| **原型法** | 需求不明、探索型 | 快速、用户参与 | 需 CASE 工具，文档不足 |
| **面向对象 OO** | 大中型、复杂业务 | 复用性好、可维护 | 需求分析要求高 |
| **面向服务 SO** | 跨组织、异构集成 | 松耦合、跨平台 | 治理复杂、性能损耗 |

### 综合性信息系统（延伸）

- **ERP**：企业资源计划
- **WMS**：仓储管理系统
- **MES**：制造执行系统（车间层）
- **PDM**：产品数据管理
- **CRM**：客户关系管理
- **SCM**：供应链管理

## §2.2–2.7 六大典型信息系统（核心考点表）

| 系统 | 服务层级 | 核心功能 | 用户 | 典型输入 → 输出 |
|---|---|---|---|---|
| **TPS** 业务处理 | 作业层 | 日常事务的记录、处理与查询 | 一线业务员 | 订单/流水 → 凭证/明细账 |
| **MIS** 管理信息 | 中层管理 | 汇总、统计、例行报表 | 中层管理者 | TPS 数据 → 管理报表 |
| **DSS** 决策支持 | 中高层 | 半结构化决策、模型分析 | 中高层管理者 | 数据 + 模型 → 决策方案 |
| **ES** 专家系统 | 专门领域 | 用知识库 + 推理机模拟专家 | 领域业务员/专家 | 事实 → 诊断/建议 |
| **OAS** 办公自动化 | 全组织 | 文档、邮件、协同、审批 | 全员 | 表单/邮件 → 归档/审批结果 |
| **ERP** 企业资源计划 | 全企业 | 财务、供应链、生产、HR 一体化 | 企业整体 | 全流程数据 → 集成经营决策 |

### DSS 四部件

**数据部件（数据库/仓库） + 模型部件（模型库） + 推理部件（方法库） + 人机接口**。

### ES 五部件

**知识库 + 推理机 + 综合数据库 + 知识获取 + 人机接口**（有的教材加"解释器"共六部件）。推理方式：正向（数据驱动）、反向（目标驱动）、混合。

### ERP 发展脉络

MRP（物料需求计划 60s）→ MRP II（制造资源计划 80s）→ **ERP（企业资源计划 90s）** → ERP II（扩展至供应链协同）。

## §2.8 典型信息系统架构模型

### 电子政务（必背四大关系）

| 类型 | 全称 | 举例 |
|---|---|---|
| **G2G** | 政府 - 政府 | 部委间数据交换 |
| **G2B** | 政府 - 企业 | 电子税务、招投标 |
| **G2C** | 政府 - 公民 | 社保查询、身份证办理 |
| **G2E** | 政府 - 雇员 | 公务员内部系统 |

### 电子商务（必背四大关系）

| 类型 | 全称 | 举例 |
|---|---|---|
| **B2B** | 企业 - 企业 | 阿里巴巴 1688 |
| **B2C** | 企业 - 消费者 | 京东、天猫 |
| **C2C** | 消费者 - 消费者 | 淘宝、闲鱼 |
| **O2O** | 线上 - 线下 | 美团、饿了么 |

也常考 **C2B**（消费者反向定制）、**B2G**（企业对政府）、**ABC**（Agents-Business-Consumer）。

### 企业信息化方法

- 业务流程重组 **BPR**
- 客户关系管理 **CRM**
- 供应链管理 **SCM**
- 产品数据管理 **PDM**
- 知识管理 **KM**
- 商业智能 **BI**（数据仓库 + OLAP + 数据挖掘）

## 必背要点速记

1. 生命周期 4 阶段：**立项 → 开发 → 运维 → 消亡**；建设 5 原则记「高层介入、用户参与、自顶向下、工程化、创新」。
2. 六大系统层级金字塔：底层 TPS，中层 MIS/DSS，顶层 ES/ERP 跨层，OAS 覆盖全员。
3. DSS 靠"数据 + 模型 + 方法 + 接口"；ES 靠"知识库 + 推理机"。
4. ERP 演化：MRP → MRP II → ERP → ERP II，核心是"从物料计划到全企业资源集成"。
5. 电子政务 4 关系：G2G/G2B/G2C/G2E；电子商务：B2B/B2C/C2C/O2O。
6. 结构化方法适合需求稳定；原型法适合需求不明；OO 适合复杂；SO 适合跨组织。

## 常考题型示例

- 【综合选择】以下关于 DSS 与 MIS 的区别，正确的是（ ）。—— 答：DSS 面向半结构化/非结构化决策，含**模型库**与**方法库**，服务中高层；MIS 面向结构化的日常管理，主要产出例行报表。
- 【综合选择】企业电子商务中，淘宝网 C2C、天猫 B2C、阿里 1688 属于（ ）。—— 答：分别为消费者对消费者、企业对消费者、企业对企业。

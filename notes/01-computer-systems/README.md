# 01 · 计算机系统基本知识（教材第 2 章 / 大纲 §1）

> 综合选择 2–5 题，占 2.7–6.7%（OS + 硬件 + 性能合计）。案例基本不直接考，但性能公式、Amdahl 是隐藏考点。

## §1.1 计算机系统概述

- **计算机系统** = 硬件 + 软件；软件又分系统软件（OS/DBMS/编译器/中间件）与应用软件。
- 分类维度：按用途（通用/专用）、按规模（巨型/大型/小型/微型/工作站）、按处理方式（数字/模拟/混合）。

## §1.2 计算机硬件

### 冯·诺依曼结构五大部件

运算器 + 控制器 + 存储器 + 输入 + 输出；核心思想：**程序存储 + 指令顺序执行**。

### CISC vs RISC（必背对比）

| 维度 | CISC | RISC |
|---|---|---|
| 指令数量 | 多（数百条），变长 | 少（几十条），定长 |
| 寻址方式 | 复杂多样 | 简单少量 |
| 通用寄存器 | 少 | 多（≥32） |
| 控制方式 | 微程序 | 硬布线 + 流水线 |
| 代表 | x86 | ARM、MIPS、RISC-V、龙芯 LoongArch |

### 处理器芯片用途

| 芯片 | 定位 | 典型场景 |
|---|---|---|
| **CPU** | 通用逻辑控制 | 服务器、PC |
| **GPU** | 大规模并行浮点 | 图形渲染、AI 训练 |
| **DSP** | 高速数字信号处理 | 音视频编解码、通信基带 |
| **FPGA** | 可编程硬件逻辑 | 原型验证、加解密加速、低时延交易 |
| **ASIC** | 定制专用电路 | 矿机、TPU |

**国产处理器**：龙芯（LoongArch）、飞腾（ARM）、鲲鹏（ARM）、海光/兆芯（x86 授权）、申威（Alpha）。

### 存储器层次（速度由快到慢）

**寄存器 → 片上 Cache（L1/L2）→ 片外 Cache（L3）→ 主存（DRAM）→ 外存（SSD/HDD/磁带）**

- 遵循 **局部性原理**（时间/空间局部性），越靠近 CPU 容量越小、速度越快、单位成本越高。
- Cache 命中率 h：平均访问时间 T = h·Tc + (1–h)·Tm。

### 总线分类

| 类型 | 位置 | 举例 |
|---|---|---|
| **内部总线** | CPU 芯片内部 | 寄存器之间 |
| **系统总线** | 主板上 CPU 与主存/IO 之间 | 数据/地址/控制总线；PCI、PCIe |
| **外部总线（通信总线）** | 主机与外设 | USB、SATA、RS-232 |

## §1.3 计算机软件

### 操作系统类型

| 类型 | 特征 | 举例 |
|---|---|---|
| 批处理 | 无交互，作业流 | 早期大机 |
| 分时 | 时间片轮转、多用户交互 | UNIX、Linux |
| 实时 | 强响应时间保证 | VxWorks、RT-Linux |
| 网络 | 提供网络服务 | Windows Server |
| 分布式 | 逻辑统一多节点 | Amoeba、Google 内部 |
| 嵌入式 | 资源受限、专用 | µC/OS、FreeRTOS、鸿蒙 LiteOS |

### 中间件（必背）

- 定义：位于 OS 与应用之间的通用服务，屏蔽异构。
- 分类：**消息中间件**（IBM MQSeries、RabbitMQ、Kafka）、**事务中间件**（BEA Tuxedo）、**对象中间件**（CORBA）、**Web 应用服务器**（Tomcat、WebLogic）。
- 作用：跨平台通信、解耦、事务一致性、可伸缩。

### 软件构件模型（必背）

| 标准 | 组织 | 语言 | 定位 |
|---|---|---|---|
| **CORBA** | OMG | 中立（IDL） | 分布式对象请求代理 |
| **J2EE / EJB** | Sun/Oracle | Java | 企业级组件（Session/Entity/MDB） |
| **COM+ / DCOM / DNA 2000** | Microsoft | 多语言 | Windows 平台组件 |

### 数据库与文件系统

- 三大数据模型：层次、网状、关系（主流）；第三代：对象-关系、NoSQL。
- 文件系统：FAT32、NTFS、ext4、XFS、ZFS。

## §1.4 嵌入式系统及软件

- **组成**：嵌入式微处理器 + 存储器 + IO 接口 + 嵌入式 OS + 应用软件。
- **特点**：专用、资源受限、实时性、可靠性、低功耗、可裁剪。
- **实时系统**：强实时（错过截止 = 系统失败，如刹车 ABS）、弱实时（延迟可容忍，如视频播放）。
- **安全攸关系统**：航空 DO-178B/C（A~E 五级）、汽车 ISO 26262（ASIL A~D）、铁路 EN 50128。

## §1.5 计算机网络

### 性能指标

| 指标 | 含义 |
|---|---|
| 速率 | 数据率（bps） |
| 带宽 | 最高数据率（bps） |
| 吞吐量 | 实际单位时间数据量 |
| 时延 | 发送 + 传播 + 处理 + 排队 |
| 时延带宽积 | 带宽 × 时延（链路容量） |
| 利用率 | 有效使用比例 |

### 网络分类与协议

- 按范围：**PAN < LAN < MAN < WAN**；WLAN（Wi-Fi 802.11）、5G（eMBB/URLLC/mMTC 三大场景）。
- OSI 七层：物 / 数 / 网 / 传 / 会 / 表 / 应。
- TCP/IP 四层：网络接口 / 网际 IP / 传输 TCP-UDP / 应用。
- 网络设备工作层次：中继器/集线器（物）、网桥/交换机（数）、路由器（网）、网关（应用）。

## §1.6 计算机语言

四代 + 建模：机器语言 → 汇编 → 高级语言 → 4GL → **建模语言（UML 4+1 视图）** / **形式化语言**（Z、VDM）。

## §1.7 多媒体

- 数据压缩：**无损**（Huffman、LZ77、PNG、FLAC）、**有损**（JPEG、MP3、H.264/H.265）。
- 特性：数据量大、实时性、集成性、交互性；VR（沉浸）/AR（增强）/MR（混合）。

## §1.9 系统性能

### Amdahl 定律（必背）

$$ S = \frac{1}{(1-a) + \frac{a}{n}} $$

- a：可并行部分占比，n：处理器数。极限 n→∞ 时 S = 1/(1–a)。
- 例：可并行 90%，无限处理器时最大加速比 = 10。

### 性能计算四法

1. **定义法**（用响应时间/吞吐量的定义直接算）
2. **公式法**（Amdahl、MIPS = 指令数 / (执行时间 × 10⁶)）
3. **程序检测法**（Profiler 插桩）
4. **仪器检测法**（硬件性能计数器）

### 性能评估

- **基准测试 Benchmark**：SPEC（CPU）、TPC-C/H（数据库）、LINPACK（超算 HPL）。
- **Web 评估**：LoadRunner、JMeter。
- **系统监视**：Windows perfmon、Linux top/vmstat/sar。

### 性能设计

- **Amdahl 优化**：先优化占比最大的部分。
- **负载均衡**：DNS 轮询、LVS（四层）、Nginx/HAProxy（七层）。

## 必背要点速记

1. CISC 变长指令 + 微程序；RISC 定长指令 + 流水线 + 大量寄存器。
2. 冯·诺依曼 = 五大部件 + 程序存储 + 顺序执行。
3. 中间件 = 位于 OS 与应用之间；MQSeries 消息、Tuxedo 事务、CORBA 对象。
4. Amdahl S = 1 / ((1−a) + a/n)，极限 1/(1−a)。
5. OSI 七层记忆：物数网传会表应；TCP/IP 四层。
6. DO-178B 用于航空安全攸关软件，分 A~E 五级。

## 常考题型示例

- 【综合选择】CISC 与 RISC 相比，下列描述正确的是（ ）。—— 答：RISC 采用大量通用寄存器 + 硬布线控制 + 定长指令。
- 【计算题】某系统 40% 代码可并行，用 4 核 CPU，加速比多少？—— S = 1 / (0.6 + 0.4/4) = 1 / 0.7 ≈ 1.43。

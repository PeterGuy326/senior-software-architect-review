# 嵌入式实时系统速查表

## 嵌入式系统 5 大特点

| 特点 | 含义 |
|---|---|
| **专用性** | 面向特定应用、软硬件可裁剪 |
| **实时性** | 结果正确性还依赖产生时间 |
| **可靠性高** | 24×7 长期稳定运行 |
| **资源受限** | CPU 主频低、内存 KB-MB 级、功耗严格 |
| **软硬件结合** | 必须协同设计 |

## 嵌入式分层架构

```
┌──────────────────────────┐
│  应用软件层（业务逻辑）  │
├──────────────────────────┤
│  中间件层（图形/网络/DB）│
├──────────────────────────┤
│  RTOS 实时操作系统       │
├──────────────────────────┤
│  BSP / 设备驱动 / 板级支持 │ ← 屏蔽硬件差异
├──────────────────────────┤
│  硬件层（CPU/MCU/外设）  │
└──────────────────────────┘
```

**BSP（Board Support Package）核心抓手**：含驱动、中断初始化、时钟配置、Bootloader 引导。**换 MCU 只需替换 BSP**——是可移植性关键。

## 硬实时 vs 软实时

| 维度 | 硬实时 | 软实时 |
|---|---|---|
| 错过 deadline 后果 | 灾难性（人身/财产损失） | 性能/体验下降 |
| 典型 | ABS 制动、飞控、机器人控制、起搏器 | 多媒体播放、HMI、IoT 上报 |
| 调度容忍 | 0 容忍 | 可容忍少量超时 |

> **关键**：实时 ≠ 快。实时强调**确定性 + 按时**，慢但每次都准时的系统也是实时的。

## 实时调度算法（必背）

### RMS（Rate Monotonic Scheduling，速率单调）

- **静态优先级**：周期短的优先级高
- **充分条件**（可调度判据）：`Σ(Cᵢ/Tᵢ) ≤ n(2^(1/n) − 1)`
- n→∞ 时趋于 **0.693 (ln 2)**
- 适合：周期任务、优先级固定

### EDF（Earliest Deadline First，最早截止）

- **动态优先级**：deadline 最近的任务优先
- **充要条件**：`Σ(Cᵢ/Tᵢ) ≤ 1`（CPU 利用率 ≤ 100%）
- 利用率上限 100%，**比 RMS 更优**
- 缺点：上下文切换多、过载行为不可预测

### RMS vs EDF

| 维度 | RMS | EDF |
|---|---|---|
| 优先级 | 静态 | 动态 |
| 可调度上限 | ~69.3% | 100% |
| 实现复杂度 | 简单 | 复杂 |
| 工业应用 | 多 | 少 |

## 优先级反转（Priority Inversion）

```
高优先级 H 等 L 持有的锁
中优先级 M 抢占 L
→ H 被 M 间接拖延，看似 H < L
```

**著名案例**：1997 火星探路者号反复复位。

### 解决方案

| 协议 | 原理 |
|---|---|
| **PIP**（优先级继承） | L 临时继承 H 的优先级，M 无法抢占 |
| **PCP**（优先级天花板） | L 申请锁时立即提升到该锁的优先级天花板 |
| **PIP-Dynamic** | 动态继承（VxWorks 改进版） |

## 常见 RTOS

| RTOS | 特点 | 应用 |
|---|---|---|
| **μC/OS-II/III** | 教学经典、源码可读 | 工控、教学 |
| **FreeRTOS** | 开源最流行、社区大 | IoT、消费电子 |
| **VxWorks** | 商业老牌、航天首选 | 火星车、波音 787 |
| **RT-Linux** | Linux 实时补丁 | 通用 + 软实时 |
| **QNX** | 微内核、稳定 | 汽车（CarPlay 基础） |
| **华为 LiteOS** | 国产、IoT 定位 | IoT 设备 |
| **RT-Thread** | 国产、组件丰富 | 工控、IoT |
| **SylixOS** | 国产、航天 | 国产航天 |

## RTOS 核心特征

| 特征 | 说明 |
|---|---|
| **任务抢占** | 高优先级就绪可立即抢占低优先级 |
| **确定性** | 中断延迟、上下文切换有上界 |
| **基于优先级调度** | 静态 RMS 或动态 EDF |
| **小内核** | KB 级，最小可剪到几 KB |
| **可裁剪** | 按需选模块 |

> **与通用 OS 区别**：通用 OS 追求公平（如 Linux CFS），RTOS 追求**确定性与及时性**。

## 中断处理两层结构

```
ISR（Interrupt Service Routine）─── 上半部
   越短越好、不能阻塞、保存现场快速处理
        ↓
任务/DPC/Bottom Half ─── 下半部
   慢处理放到任务上下文执行
```

## 嵌入式开发模式

| 模式 | 含义 |
|---|---|
| **宿主机/目标机** | PC 上交叉编译，烧录到目标机执行 |
| **交叉编译** | 一种 CPU 上生成另一种 CPU 的可执行程序（如 x86 → ARM） |
| **JTAG / SWD** | 调试接口，可在线烧录、断点调试 |
| **Bootloader** | 上电首先运行的引导程序（U-Boot 最常用） |
| **OTA** | 远程固件升级 |
| **看门狗（Watchdog）** | 软件卡死时硬件复位 |

## AADL（嵌入式架构语言）

- **A**rchitecture **A**nalysis & **D**esign **L**anguage
- SAE 国际标准，工业级使用
- 描述软硬件混合的嵌入式系统
- 支持时序、调度、可靠性分析
- 典型应用：航空电子、汽车 ECU

## 常考公式

| 项 | 公式 |
|---|---|
| RMS 充分条件 | Σ(Cᵢ/Tᵢ) ≤ n(2^(1/n)−1) |
| EDF 充要条件 | Σ(Cᵢ/Tᵢ) ≤ 1 |

| MTBF | MTTF + MTTR |
| 可用性 A | MTTF / (MTTF + MTTR) |

# 对话页主观题训练

0.5.0 接通原生小程序、CloudBase 私有 PostgreSQL RPC、免费 Qwen/Qwen3-8B 和已有语音转写。无需新增域名或付费模型。

语音转写固定使用同平台 `XingChenAGI/XingChenASR-V3.2-Ultra`，2026-11-02 已核对官方动态价格为免费，并通过合成 MP3 实测；原 SenseVoiceSmall 当时多次超时。不自动回退付费型号，后续价格变化需重新核实。

## 用户流程

- 聊天输入框上方点“案例”，读取一道原创短案例；点麦克风分段回答，转写可以修改；点“评分”后在原对话里查看反馈。
- 点“论文”，从微信文件选择 DOCX、文字版 PDF 或 TXT。文件选好后可点“选题”挑一道论文仿真题，也可以自拟补充题目或直接点“批改”。未确认时不上传。
- 主卡显示 AI 估分与一个优先改进点，展开后可查逐点评分和原文依据。离开重进后仍能找到任务和批改。失败可重试，也可先放下。

## 评分与进度

`exam_packs/ruankao-system-architect/subjective.json` 保存版本化的固定题目和评分点：12 道原创短案例覆盖架构评估、缓存消息、微服务、数据库、安全、高可用容灾、大数据与云迁移（对应课程 C01–C08 考点）；`essay_topics` 提供 12 道按 2009–2025 年历年真题方向原创的论文仿真题，映射 P01–P06 论文考点，不复制真题原文。案例按 25 分练习口径，论文按 75 分口径；两者均非官方阅卷分。

`apps/api/subjective.py` 将作答标注为原文片段。模型只判定各点是否命中及证据片段编号，后端从原文取证，再调用 `scripts/grade.py` 计算分数。缺点、重复点或无效证据会拒绝保存；相同请求的报告不可改写。自由聊天工具只能提供入口，不能直接写分或修改已保存的报告。

未提供论文试题时，评价文稿内部主题一致性，不能声称符合某一道官方题目。选择仿真题（`topic_ref`）时，题目原文作为切题依据传入通用论文评分点，学习事件记录到该仿真题自己的课程考点；选题与自拟题目互斥。外部项目真实性无法核实。未计时上传或不足 2500 字的文稿只保存为批改记录，不提升为完整限时论文掌握证据；案例按现有练习进度协议记录，短练习不预测完整考试成绩。

## 文件与隐私

支持 2 MB 以内、最多 20 页的文字版 PDF、DOCX、TXT，正文最多 18000 字。扫描或纯图片 PDF、加密 PDF、旧版 DOC、可读正文不足 100 字的文件给出明确提示。文件解析在有 CPU、内存、时间和并发限制的子进程中进行，不执行宏或读取外部 XML 实体。

原始文件与音频不落后端磁盘或对象存储；作答正文、文件名、评分点报告保存在当前账号私有数据库中。模型只收到必要的题目、评分点和文稿文字，不收到账号标识或密钥。首次批改需要用户确认文稿处理说明，微信隐私授权仍由平台处理。

超过 60 KB 的编码文稿和录音自动分片传输，每个分片 JSON 小于 70 KB。分片仅在后端受限内存中保留，绑定已验证的账号会话与学习目标，最长 5 分钟，取用后立即移除；重启丢失时用户可重试。不会为此新增对象存储或公开上传域名。小文稿和短录音直接传输以减少操作延迟。

数据库增加 `coach.subjective_issues`、`coach.subjective_reviews`。全部访问经后端专用 RPC，校验会话与目标归属；匿名角色不能执行。异步租约、有限重试、每日额度和原始输入哈希防止重复生成与改写；写学习状态使用原子比较更新。

## 发布与验收

先应用 `cloudbase/migrations/20261102020000_subjective.sql`，再部署 API，最后上传小程序。新增考试可复用文件、评分与异步引擎，另加考试包、固定评分规则、稳定课程考点映射。题库扩充（案例与论文仿真题）只改考试包文件，随 API 部署生效，无需新增数据库迁移；课程表新增 C05–C08 案例扩展赛道必须随新内容发布版本上线（`scripts/publish_cloud_content.py` 发布 → 更新 `.env` 的 `CONTENT_RELEASE_ID` → 部署），否则旧发布版本的目标批改新赛道案例会因考点校验失败。小程序 goal 缓存带发布版本标记，版本切换后自动创建新目标（旧目标记录保留在云端）。

免费档模型存在动态 TPM 限流：单次批改请求约数千 token，密集调用可能触发 429，批改标记失败后可用原内容重试，不会重复记分；验收脚本之间应留足配额窗口。

```sh
uv run python -m scripts.verify_subjective_cloud --provision
npm run deploy:dev
uv run python -m scripts.verify_subjective_cloud --deployed
npm run test:mini
```

真实模型验收脚本只创建独立合成账号，结束后精确清理该账号的数据；测试文稿和结果位于忽略的 `.study/platform/`。手机最终验收包括案例语音评分、论文选文件/取消/提交、展开依据、重进恢复和深浅色阅读。
